# Colaboradores del proyecto

Este proyecto fue desarrollado de manera colaborativa por cinco integrantes, cada uno responsable de investigar y documentar las variantes genéticas de un gen humano seleccionado.

## Organización del trabajo

Cada integrante contribuyó al repositorio mediante archivos CSV con la información de las variantes seleccionadas y archivos Markdown con la documentación de su respectivo gen.

Las contribuciones se organizaron mediante ramas de trabajo, commits y pull requests, permitiendo integrar los aportes individuales en un repositorio compartido.

El resultado es un catálogo colaborativo de variantes genéticas humanas que combina la consulta de información biomédica con el uso de herramientas de control de versiones.
